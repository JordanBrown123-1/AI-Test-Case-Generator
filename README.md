# 🧪 Software Test Case & Bug Report Generator

A Python web application that generates structured software test cases, identifies edge cases, and creates professional bug reports from software requirements.

[Launch Software Test Case & Bug Report Generator](https://jordan-ai-test-generator.streamlit.app)

## ✨ Features

- Generate structured software test cases from feature requirements
- Functional, Negative, Boundary, Security, and Usability testing
- Automatic feature-type detection
- Feature-specific test case generation
- Test case IDs, priorities, preconditions, steps, and expected results
- Automatic edge-case identification
- Structured bug report generation
- Automatic bug severity and priority classification
- Reproduction steps, expected results, and actual results
- Downloadable test case reports
- Downloadable bug reports
- Input validation and error handling

## 🛠️ Tech Stack

- Python
- Streamlit
- Rule-based feature classification
- Rule-based test generation
- Git & GitHub
- Streamlit Community Cloud
